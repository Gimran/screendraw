# ScreenDraw

Утилита для скриншотов области экрана с аннотациями (Windows, C# / WPF, .NET 10).

## Сборка и запуск
```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o dist
dist\ScreenDraw.exe
```
Живёт в трее. Левый клик по иконке — скриншот, правый — меню (настройки, выход).

## Использование
- Хоткей по умолчанию **Ctrl+Shift+`** (меняется в настройках: поле ловит нажатое сочетание). Если сочетание занято другой программой, будет уведомление.
- Выделите область мышью (ПКМ / Esc — отмена) → откроется редактор.
- Инструменты: **V** выбор, **A** стрелка, **L** линия, **R** рамка, **O** овал, **T** текст. Shift — угол 45° / квадрат.
- Ctrl при нажатии — временно «выбор» (переместить объект, не переключая инструмент).
- Рамки как в CorelDRAW: клик по объекту — 8 маркеров масштаба (угловые — пропорционально, Shift — от центра; у текста меняется размер шрифта). Повторный клик по выбранному — режим поворота: угловые маркеры вращают вокруг точки-перекрестия, её можно перетащить в любое место (Shift — шаг 15°). Ещё клик — назад к масштабу. У линий/стрелок есть маркеры концов.
- Тянуть объект — переместить, Delete — удалить, стрелки — сдвиг на 1px; смена цвета/толщины применяется к выбранному. Двойной клик по тексту — править.
- Ctrl+Z / Ctrl+Y — отмена/повтор, Ctrl+C — в буфер, Ctrl+S — в папку, Ctrl+Shift+S — «Сохранить как», Esc — закрыть.
- Настройки: `%APPDATA%\ScreenDraw\config.json` (папка, хоткей, автозапуск и т.д.).
